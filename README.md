# Signo Consultorio

Programa de consulta de **Signo · Medicina Integral** (Dr. Yassir Josué Dumani Manzano): atención médica con formularios MSP (HCU 2021), recetas, certificados, órdenes de laboratorio, curvas OMS, ficha SIVE-Alerta y base de datos en Excel.

- Abrir: https://signoy.github.io/signo/
- **Los datos de pacientes no se guardan en este repositorio ni en internet**: quedan solo en el navegador de cada equipo. Este repositorio contiene únicamente el programa.
- Respaldos: «Ajustes y respaldo» dentro del programa.
